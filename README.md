# BeamNG Texture Editor

محرر تكسترات محلي بواجهة عربية متجاوبة، موجه للاستخدام من الجوال.

## الموجود حالياً
- واجهة RTL متجاوبة مع شاشات الجوال.
- استيراد صور PNG وJPG وWEBP من الجهاز.
- قائمة صور مستوردة مع بحث وتصفية فورية.
- معاينة الصورة وإضافة نص فوقها.
- تحميل خط مخصص بصيغة TTF وتغيير الحجم واللون.
- تصدير الصورة المعدلة بصيغة PNG.
- غلاف PWA وتخزين ملفات الواجهة للعمل دون اتصال بعد أول زيارة.

## حدود المرحلة الأولى
هذه نسخة تأسيسية لمحرر الصور. لم يُنفذ بعد فتح أرشيفات سيارات BeamNG أو قراءة ملفات DDS أو إعادة بناء حزم ZIP. لن تُعرض هذه الوظائف على أنها مدعومة قبل إضافة مكتبات المعالجة واختبارها على Safari في iOS.

## تشغيل محلي
افتح المشروع عبر خادم صفحات ثابتة (مثل GitHub Pages). لا يحتاج إلى خادم تطبيق أو حساب مستخدم؛ معالجة الصور الحالية تتم داخل المتصفح.

## المراحل التالية
1. دعم ZIP واستعراض ملفات السيارة مع البحث والتصفية.
2. قراءة صيغ التكسترات الفعلية وتحديد صيغة الإخراج تلقائياً.
3. تحويل الصور إلى الصيغة المطلوبة دون أسئلة إعدادات للمستخدم.
4. إعادة بناء حزمة السيارة مع إبقاء الملفات غير المعدلة كما هي.
5. اختبارات توافق فعلية على Safari في iOS.
6. إضافة مجلد الخطوط المرفقة إن لزم في المرحلة الأخيرة.

## الخصوصية
لا يتم رفع الصور إلى خادم في هذه المرحلة؛ الملفات تُقرأ وتُعالج محلياً داخل المتصفح.
