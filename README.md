# BeamNG Texture Editor

محرر تكسترات محلي بواجهة عربية RTL متجاوبة للجوال.

## الميزات الحالية
- فتح أرشيف سيارة بصيغة ZIP داخل المتصفح.
- فهرسة ملفات PNG وJPG وWEBP وDDS داخل الأرشيف.
- البحث باسم الملف أو مساره، والتصفية حسب الصيغة.
- معاينة PNG وJPG وWEBP وDDS بصيغ DXT1 وDXT3 وDXT5 وبعض صيغ DDS غير المضغوطة.
- استبدال التكستر بصورة PNG أو JPG أو WEBP مع التحويل التلقائي إلى امتداد التكستر الأصلي.
- عند الاستبدال إلى DDS، يُنشأ DDS غير مضغوط RGBA مع إنشاء mipmaps أساسية حسب عدد mipmaps المسجل في الملف الأصلي.
- إضافة كتابة فوق التكستر، واستيراد خط TTF، وتغيير الحجم واللون.
- حفظ التعديل داخل الأرشيف ثم تصدير ZIP جديد.
- استيراد صورة منفردة وتصديرها PNG.
- لا يوجد رفع للصور أو الأرشيف إلى خادم التطبيق.

## تشغيل
المشروع تطبيق ويب ثابت. افتحه عبر GitHub Pages أو خادم HTTPS ثابت. تُحمّل مكتبة JSZip من jsDelivr عند فتح التطبيق لأول مرة؛ بعد تفعيل Service Worker يمكن أن تتوفر من التخزين المؤقت.

## حدود تقنية مهمة
- دعم DDS الحالي للمعاينة يشمل DXT1 وDXT3 وDXT5 وبعض DDS غير المضغوطة؛ صيغ DX10/BC7 وBC5 وغيرها غير مدعومة للمعاينة بعد.
- استبدال DDS ينتج DDS بصيغة RGBA غير مضغوطة، وليس DXT؛ يجب التحقق من توافق الناتج مع كل سيارة/مادة داخل BeamNG قبل اعتباره بديلاً مضموناً.
- ملفات ZIP المشفرة غير مدعومة.
- لا يتم فك الأرشيف إلى نظام الملفات؛ تتم المعالجة داخل ذاكرة المتصفح، لذا الملفات الضخمة قد تتجاوز ذاكرة بعض الهواتف.
- تحويل JPG يحافظ على الامتداد لكنه يستخدم ضغط JPEG؛ الصور ذات الشفافية لا تناسب JPG.
- لا يدّعي نجاح التوافق داخل اللعبة قبل الاختبار على ملفات سيارات فعلية.

## الخصوصية
تتم معالجة ملفات المستخدم محلياً داخل المتصفح. لا يرسل التطبيق ملفات السيارات أو الصور إلى خادم. مكتبة ZIP فقط تُحمّل من CDN عند الحاجة.
